# Mobile App

Flutter app for ChessBraining.

Expected generated project path:

```text
apps/mobile/chessbraining_app
```

Create it with:

```powershell
cd apps/mobile
flutter create chessbraining_app
```

Suggested package organization:

```text
lib/
  app/
  core/
    config/
    networking/
    realtime/
    theme/
    widgets/
  features/
    auth/
    lobby/
    match/
    brain_round/
    powerups/
    history/
    profile/
```

First screens to build:

1. Login/register screen.
2. Lobby screen.
3. Create/join match screen.
4. Match screen.
5. Brain round screen.
6. Match result screen.
