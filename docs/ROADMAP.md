# Roadmap

## Milestone 0: Repo Setup

- Add docs.
- Create GitHub repo.
- Add teammates.
- Set up project board.
- Decide package names and app name.
- Create initial Flutter and Spring Boot projects.

## Milestone 1: Local Prototype

Goal: prove the core gameplay loop on one machine.

- Flutter board screen.
- Spring Boot match state.
- Legal chess moves.
- Manual match creation.
- Brain round trigger.
- Mental math mini-game.
- Brain Points reward.
- One power-up.

## Milestone 2: Online MVP

Goal: two real players can complete a match.

- Accounts.
- Invite codes.
- WebSocket match sync.
- Chess timers.
- Three power-ups.
- Basic match history.
- Reconnect support.
- Android test build.

## Milestone 3: Alpha Test

Goal: test fun and balance with 20 to 50 people.

- Better onboarding.
- Multiple brain mini-games.
- Move timeline.
- Replay screen.
- Balance event logging.
- Feedback form.
- Bug reporting flow.

## Milestone 4: Public Beta

Goal: launch to a wider audience.

- Casual matchmaking.
- Player profiles.
- Basic rating.
- Spectator mode.
- Push notifications.
- Anti-cheat improvements.
- Production monitoring.

## Milestone 5: Competitive Mode

Goal: make repeat play meaningful.

- Ranked queues.
- Seasons.
- Tournaments.
- Class-based powers.
- Leaderboards.
- Stronger replay tools.

## Suggested Timeline With AI Assistance

For a small team:

| Stage | Time Estimate |
| --- | --- |
| Repo setup and planning | 1-3 days |
| Local prototype | 1-2 weeks |
| Online MVP | 3-6 weeks |
| Alpha-ready version | 2-3 months |
| Polished public beta | 4-6 months |

These estimates assume the team keeps scope tight and avoids building too many powers before the core loop is tested.
